# v0.10 S18 qualification — NetworkManager connectivity

**Status:** Proposed qualification scope; no new native network effect or release support qualified.
**Profile:** `arch-hyprland-v1`; dependency S16.
**Authority:** [ADR 0048](../adr/0048-s18-networkmanager-authority.md), [inactive S18 design](../../contracts/v010-s18-design.toml), [S18 security](v0.10.0-s18-security.md).

## Evidence ownership and oracles

S18 refines v0.10 Q9 (provider/effect), Q10 (experience), Q11 (hardware), Q12 (recovery) and Q13–Q14 (security and inherited gates). Every native effect case must bind actual source SHA, target/NetworkManager version, system-bus unique owner, boot, device/profile/active-connection epochs, authenticated subject, requested postcondition, before/after observation, durable attempt and reconciliation lineage. Native reply or video never substitutes for an independent verified postcondition. A mock or virtual Ethernet NIC does not establish physical Wi-Fi support.

## Required positive/negative matrix

| Domain | Native acceptance | Failure/denial |
| --- | --- | --- |
| Health/provider | Live NM system-bus owner and native ping/read | Activatable-only service, lost owner, timeout, degraded health |
| Device inventory | Managed/unmanaged/loopback and actual carrier/device state | Duplicate name, recycled ifindex, vanished device, giant response |
| Wi-Fi inventory | Bounded device-scoped AP/SSID/security/scan freshness | RF-kill, stale AP, changed radio, SSID collision, denied active scan |
| Profiles/connections | Saved revision versus active activation; exact device bindings | Replaced UUID/profile revision, stale ActiveConnection, missing secrets |
| IP and DNS | Native IPv4/IPv6/gateway/default routes/DNS and effective activation | Split-family failure, DHCP/DNS partial application, captive portal |
| Network/radio changes | Trusted managed Control effect and fresh verified postcondition | Last usable link blocked, foreign Polkit subject, late provider restart |
| Connect/deactivate/join | Identity-bound plan, protected credential entry, independently checked result | Wrong AP/profile, lost reply, unauthorized retry, ambiguous outcome |
| Profile changes | Typed allowlist and revisioned create/update/delete | Unsafe shared owner, untrusted settings, no recovery, secret export |
| Experience | Same state/operation/risk from GUI, CLI/SDK, manual/no-model | Optimistic UI success, stale cache, keyboard/a11y/HiDPI drift |
| Recovery | Durable indeterminate state and accessible offline local recovery | Missing native route, disconnected remote actor, shell crash, replay |

For every `ManagedExternalEffect` exercise success, no-change, denial, stale approval, altered resource, pre-dispatch failure, effect failure, independently failed verification, timeout/lost reply, restart before/after dispatch, reconcile and no-replay. No-change does not skip policy. Provider state `Connectivity=FULL` is still an NM-reported category, not independently proven Internet reachability.

## Qualification levels

**A — automated exact-source Arch/Hyprland VM:** Actual native NM system bus, virtual Ethernet, isolated network profile and route/DNS fixtures, exact-source Control transactions and negative evidence; no model dependency. A fake observer alone is a contract test, not Level A.

**B — interactive VM:** Exact same pinned source/substrate; real shell, keyboard/focus/pointer/accessibility, dual-stack/offline UI and protected-secret transitions. Does not substitute for physical radio.

**C — maintained physical workstation/Q11:** Independently nonvirtual target evidence for actual supported network adapters, Wi-Fi scan/association/roaming/rfkill, recovery without reachable network, physical accessibility and provider/boot/session/source binding. Physical support remains pending until actual retained Q11 evidence exists; do not set `interactive_workstation.evidence_ready` on design/VM results.
