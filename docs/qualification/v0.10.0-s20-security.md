# v0.10 S20 security qualification — session graph, microphone privacy and media control

**Status:** Proposed adversarial acceptance; not evidence of new qualified runtime effects.
**Architecture:** [ADR 0050](../adr/0050-s20-audio-media-authority.md), [domain qualification](v0.10.0-s20.md), [system threat model](../threat-model.md).

## Security objective

An attacker-controlled node/player/metadata or foreign session must not retarget an approved audio action, misrepresent microphone capture privacy, execute arbitrary commands via media interfaces, replace the sealed audio helper, lower trusted operation class or use an old UI draft/receipt to fabricate completion.

| Threat/failure | Required adversarial case | Independent proof |
| --- | --- | --- |
| Recycled PipeWire numeric node | Replace exact node ID with different object.serial/name | Pre-dispatch revalidation denies target migration |
| Default-output or port drift | Switch default after user starts draft | Default alias cannot authorize a different node |
| Session/UID substitution | Foreign user/session bus or logind epoch change | Same-UID and selected session owner rejects effect |
| Helper integrity | Replace installed Lua, writable/symlink/hardlink, untrusted namespace owner | Existing fixed embedded/sealed helper fails closed |
| Shell/command injection | QML/agent requests raw wpctl/script or PipeWire method | Registered typed operation/allowlist only |
| Transient downgrade | Mute/source/profile/route falsely claimed covered by output-volume descriptor | Exact registry, material keys, class/risk and policy reject |
| Capture/source confusion | Input source treated as Audio/Sink, foreign stream retarget | media.class, owner, stream/port/link generations prevent effect |
| Privacy misrepresentation | Input muted but raw capture continues via another path | Separate hardware/software mute and active capture evidence; no kill-switch claim |
| Unauthorized capture | Other app source permission misinterpreted as Linura approval | Explicit permission evidence and native access control; never implied |
| Ambiguous route/profile | Dispatch reply lost after link/profile changed, daemon restarted | Durable managed indeterminate/re-observe, no blind replay |
| Mixed native graph | Node/card/profile/links change during multi-object observation | Inconsistent generation rejected, not atomic snapshot invented |
| MPRIS owner spoof/recycle | Reuse well-known name, replace unique owner mid-Play | Same user-bus/unique-owner/player epoch rejected |
| Malicious media metadata | Player exports huge title, markup, external artwork URI, malformed track id | bounded escaped presentation, no arbitrary URL/network fetch |
| MPRIS capability lie | Unsupported Play/Next/Seek, track auto-advances between plan and call | Current capability/track and correct bounded postcondition |
| Cross-user MPRIS effect | Other user's player exposed by untrusted bus path | authenticated same-user bus and service owner check |
| Audit fail | sqlite FULL/WAL fail, reused attempt ID, missing reservation | no dispatch or fabricated terminal; inherited S08 contract |
| Unverified success | Native helper/mixer/MPRIS returns success before postcondition | strictly post-dispatch independent authority or unknown |
| UI/OSD privacy | Logging microphone/device/player metadata or leaking protected screen | sanitized bounded diagnostics and authenticated session scope |
| S17/S19/S21 crossover | Lock, power, Bluetooth profile switch during route/selection | S17 lock and S21 power recovery intact; no stale graph permit |
| Virtual-hardware proof | Virtual source used to claim physical microphone privacy | evidence class Q11 denial |

## Failure/recovery matrix

For each supported action exercise preplan, postauthorization/preparation, prepared-before-dispatch, native effect pending, lost method reply, postdispatch verification, commit/audit and restart reconciliation. A stale/currently absent MPRIS player or PipeWire stream cannot be silently retargeted to another display name or current default. Do not replay a managed ambiguous effect; transient support is limited to operations provably free of durable indeterminate recovery.

The current S08 volume operation has a specifically reviewed bounded transient failure model and must not be silently transformed into managed or widened to include source/mute/route. Audit secrets and protected metadata remain absent from all evidence. Passing contract fixtures or recorded videos cannot establish real session permission, physical capture assurance or Q11 release proof.
