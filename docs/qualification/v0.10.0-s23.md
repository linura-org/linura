# v0.10 S23 qualification — applications, Arch packages and default handlers

**Status:** Proposed; not evidence of installed executable effects, S24 recovery or physical support.
**Target:** `arch-hyprland-v1`, S16 predecessor and S24 downstream.
**Authority:** [ADR 0052](../adr/0052-s23-application-package-and-default-handler-authority.md), [design](../../contracts/v010-s23-design.toml), [security dossier](v0.10.0-s23-security.md).

## Exact native proof

Retain exact source SHA, pinned Arch repository/archive/sync DB identities and signed package/keyring hashes, pacman/libalpm versions, local DB generation/lock owner, requested package names/versions/architecture, complete resolved dependency/replaces/conflicts/removal closure, installed file ownership, native authenticated Polkit subject and current S24 coordinator state. Package manager return code alone cannot establish success. XDG default app operations additionally bind current user/desktop/XDG config precedence, verified desktop file and MIME association, safe config revision and independently resolved effective handler. Every test and report must distinguish intended operation, native dispatch, later observation and recovery status.

## Native capability acceptance

| Domain | Positive native case | Required negative case |
| --- | --- | --- |
| Existing S12/S14 app launch | Visible/eligible ID, fresh source re-resolution, fixed user-systemd/app.slice cgroup | NoDisplay/Hidden/Terminal, stale ID/Exec, reserved shell item, broken broker |
| App inventory | XDG ordered search, current source/owner and parsed safe display facts | Desktop ID shadow/replacement, stale TryExec, malformed/huge Exec/title |
| Installed packages | Real bounded local ALPM version/arch/repo/file ownership/installed reason | Missing/corrupt/locked DB, unsafe package aliases or stale local generation |
| Frozen catalog | Exact signed immutable repo/sync DB/keyring state, complete closure | Mirror/metadata/key substitution, changed dependency graph or signature denial |
| Install and reinstall | Current approved target, native safe transaction and exact installed postcondition | Partial upgrade, `-Sy` isolated, arbitrary `-U`, scriptlets/unsynced dependencies |
| Remove and orphans | Explicit exact removal set, reverse dependencies and shared protected owner review | Unplanned cascade, Linura/PAM/kernel/security deletion, foreign package |
| In-flight package transaction | Native pacman lock, durable prepared attempt, independent post-effect read | Contention/S24 coordinator, disk full, scriptlet failure, lost reply, reboot |
| Source/permission security | Trusted repo + real native subject + exact plan/diff/risks | Wrong UID/Polkit, AUR/PKGBUILD, unsigned source, flag/env injection |
| MIME effective lookup | Actual XDG default/Added/Removed file precedence and installed handler eligibility | Shadow mimeapps, invalid type, hidden app, scheme redirect |
| User handler set/reset | Safe atomic user config revision and fresh independently effective result | Symlink/hardlink, wrong owner, race, reset exposing fallback |
| Association add/remove | Separate group semantics and preservation of unrelated MIME entries | Simultaneous edit, lost group, wrong desktop ID, file substitution |
| Local favorites | Revisioned authenticated Linura state; no package/app launch grant | Foreign UID, stale revision, hidden app, corrupted store |
| First-party UX | One Control state/risk/operation in GUI, CLI, SDK and no-model | QML pacman, optimistic approval, lost progress, keyboard/a11y/HiDPI |
| S24 integration | Correct handoff/denial for upgrades and recovery-critical change | False snapshot promise, direct guard override, premature S24 success |

All activated managed operations require canonical request/observe/plan/validate/authorize/prepare/execute/independently verify/commit/audit/reconcile. Exercise no-change with policy check, denial, stale or revoked review, changed package universe, changed source/handler, crash before/after dispatch, missed method reply, full/corrupt audit, indeterminate recovery and no automatic replay. Exact-source native effects must run only on disposable prepared machines, not on the maintainer host.

## Qualification levels

**Level A — automated Arch VM:** Actual ALPM/pacman and real package DB against a controlled frozen signed repository, native typed package effects and security/scriptlet failure cases, real XDG handler precedence. A mock DB parser is unit evidence only.

**Level B — interactive Hyprland VM:** Same pinned source/runtime with package transaction preview, protected authorization, native postconditions, desktop launcher and handler selection, focus/keyboard/screen reader/scale/no-model paths. Not real power loss or physical support.

**Level C — maintained physical workstation/Q11:** Real installed profile, actual app/handler/desktop experience and source-/boot-/hardware-bound approved cases, with separately supported S24 real update/rollback/power-loss recovery. Do not convert a VM pacman success into hardware evidence.

Preserve S12/S14 launcher regressions, v0.9 update guard, v0.4/v0.6 managed authority, S17 protected sessions, S21 power/display and all Q9–Q14 exact-head gates. S23 remains planned until dependency-closed merged PR evidence; this dossier does not register operations or set `interactive_workstation.evidence_ready`.
