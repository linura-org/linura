# v0.10 S25 adversarial qualification — theme and wallpaper asset boundaries

**Status:** Proposed; no native safe decoder, compositor or accessibility evidence attested.
**Sources:** [ADR 0053](../adr/0053-s25-personalization-authority-and-safe-rendering.md), [domain qualification](v0.10.0-s25.md), [threat model](../threat-model.md).

## Security invariant

An imported theme, local image, icon/font, stale preference revision, untrusted session or malicious content must not execute QML/JS/shell commands, become a Linura policy approval, modify the protected lock owner, hide warning/error semantics, replace a compositor output without current authorization, or misrepresent the applied renderer state.

| Threat/failure | Required adversarial test | Independent expected outcome |
| --- | --- | --- |
| Theme code injection | Theme field contains QML/JS/CSS/shader/source path or policy token | Strict typed schema rejects, no executable evaluation |
| Schema downgrade/newer format | Unrecognized version, removed semantic role, duplicate/noncanonical setting | Explicit incompatible/unknown; no implicit default or authority |
| Concurrent CAS | Two users/panels modify same revision, or old preview applies late | One valid revision commit; stale request rejected |
| Torn persistence | Full disk, crash around rename/sync, corrupt payload/digest | Prior valid revision or explicit recovery-required, not false success |
| Cross-user preference | Foreign UID/session or forged principal writes/loads another user's settings | Actual trusted owner/permissions and session scope deny |
| Preview persistence | Lock, logout or renderer crash during preview | Cancel/invalidate without durable or native mutation |
| Wallpaper path substitution | Symlink/hardlink/TOCTOU, untrusted directory, relative traversal | Safe file descriptor and original content hash deny |
| Image resource exhaustion | Gigantic pixels, decompression bomb, animation frames, nested metadata | Bounded decode and fail closed before render |
| Malicious SVG/URI | External image references, scripts, remote URLs, file exfiltration | No script/network fetch or unsafe decoder execution |
| Font/icon injection | Fonts/images with unsafe glyphs, path aliases or executable theme metadata | Installed allowlist and safe fallback |
| Fontconfig isolation | User theme injects config into S17 auth/lock process | Secure fonts.conf/environment unmodified and protected |
| Accessibility attack | Accent makes denial indistinguishable from success; low focus contrast | Protected semantic roles, contrast and focus gate deny |
| Reduced-motion bypass | Imported theme sets mandatory animation despite user setting | User accessibility override enforced |
| Fake applied state | User CAS save succeeds but Qt/Hyprland renderer fails | Saved separate from applied; no optimistic verified receipt |
| Output substitution | Display hotplug/rename/geometry change between plan and wallpaper apply | S21 topology epoch mismatch, no retargeted wall |
| Compositor/provider death | Native reply lost or compositor restarts after write | Indeterminate/fresh reobserve; no blind replay |
| Shell/CLI bypass | QML runs hyprctl/swww/gsettings, agent sends raw config | No generic shell or external provider forwarding |
| Lock/session confusion | New seat, lock, First Boot or nonowner user while applying | No S17 security or foreign-session mutation |
| Cross-surface mismatch | First Boot, shell, Control Center and OSD render different revisions | Per-surface applied revision discrepancy visible |
| Mock qualification claim | Token tests/VM PNG used as physical UI or accessibility proof | Reject unsupported Q10/Q11 promotion |

## Required failure windows

Test before revision check, after local transaction prepare, between fsync/atomic replace and acknowledgement, between preview and native apply, during wallpaper file open/decode, after native compositor dispatch and before independent verification, after display hotplug, during lock/session switch and post-crash reconstruction. Native external failures remain indeterminate until actual same-target re-observation. A saved preference may be independently correct while applied wallpaper is unknown; preserve this distinction, do not roll back completed user settings silently or replay prior approval.

Do not log full local file paths, user photos, unbounded font/theme strings, sensitive content, provider diagnostic text or credentials into audit, model context, visual qualification or notifications. A test theme bundle or replay video never creates security, Q10 or physical Q11 evidence without its independently verified source/renderer/interaction binding.
