# v0.10 S18 adversarial qualification — NetworkManager identity, secrets and connectivity

**Status:** Proposed; no qualified S18 native effect security evidence.
**Architecture:** [ADR 0048](../adr/0048-s18-networkmanager-authority.md), [S18 domain qualification](v0.10.0-s18.md).

## Security invariant

The machine must never accept a stale/untrusted adapter, NM service owner, AP, saved profile, activation, caller or permit as authority; leak protected Wi-Fi/802.1X secrets; remove the only recoverable local network without adequate safeguards; or report uncertain native effect as success.

| Attack or fault | Negative test | Independent oracle |
| --- | --- | --- |
| Reused interface, ifindex, MAC, device path | Rename/replace between plan/dispatch | Epoch mismatch; no effect |
| Swapped NM D-Bus owner | Restart after GetDevices/health, during GetAll or dispatch | Exact unique owner; mixed snapshot denied |
| Duplicate device alias or AP SSID | Collision/roam while reviewing | Ambiguous identity rejected, never first match |
| Replaced profile/activation | Concurrent Update2, reissued UUID or active path | Current revision/generation mismatch |
| Fake operation class/risk | Active scan claimed as query; disconnect as transient | Trusted registry/policy denies downgrade |
| Foreign caller and Polkit subject | Wrong UID, seat, session or ambient root laundering | Native authenticated subject rejects |
| Secret-agent spoof | Fake auth challenge, replayed PSK, cancelled prompt | Protected purpose, no logging/agent exposure |
| Unsafe profile fields | Arbitrary settings, routes, unsafe DNS, bad type | Typed allowlist and material-diff denial |
| Radio disabled or rfkill | Scan/connect attempted without supported radio | Explicit blocked/unsupported, no fallback |
| Lost network access | Last default IPv4/IPv6 route or Ethernet removed | Viable local recovery required or deny |
| Misleading success | Link up but DHCP/DNS missing, captive portal | Independent postcondition and distinct reachability status |
| Missing native reply | Effect applied, timeout/daemon crash or peer loss | Durable indeterminate, re-observe; no blind replay |
| Unbounded input | Huge AP/device/profile/variant, hung provider | Fail closed within fixed budgets |
| Lost audit storage | Persistence full/corrupt after prepare | No unauthorized dispatch or fabricated commit |
| Stale GUI/cache | Restart and reissue old connection command | New auth + fresh observation, no replay |
| S17/S21 crossover | Lock/seat/boot change or power transition mid-effect | No protected-session or display/power bypass |
| Mock hardware claim | Virtual NIC used to claim physical radio | Explicit evidence class, no Q11 promotion |

Test crash windows before prepare, after reservation/before effect, after native dispatch/before reply, during independent verification and during commit/reconcile. Replay after any unknown result is forbidden until fresh state resolves the earlier attempt. An external native administrative recovery option does not create a Linura policy override.

No plaintext password, WPA key, EAP challenge, VPN token or unbounded SSID/BSSID/profile metadata may enter logs, audit, model context or retained test artifacts. Retained proof binds actual source/boot/NM owner/adapter/subject and separate verifier observations. Mock tests and video never establish network effect or physical support qualification.
