# v0.10 S25 qualification — themes, wallpaper, fonts, icons and preferences

**Status:** Proposed acceptance scope. No persistent personalization feature or system/compositor effect is activated.
**Target:** `arch-hyprland-v1`, depends on S16.
**Contracts:** [ADR 0053](../adr/0053-s25-personalization-authority-and-safe-rendering.md), [inactive S25 design](../../contracts/v010-s25-design.toml), [adversarial security](v0.10.0-s25-security.md).

## Baseline and oracle distinction

Preserve S10 `design/tokens.json` semantic vocabulary and the actually compiled `org.linura.UI 1.0` SDK consumed by S16 shell panels. Those files are not a persisted preference engine; `LinuraTheme.qml` currently uses `SystemPalette` for primary colors. Level A tests must bind actual source SHA, token schema/module version, persisted user/owner/revision, current native renderer and compositor/monitor identity, effective applied revision and independent visual captures. Source diff and screen image are distinct evidence. A successful settings transaction is not verified wallpaper application or cross-surface visual consistency.

## Required domain acceptance

| Domain | Positive independent proof | Required failure/negative proof |
| --- | --- | --- |
| Existing compiled SDK | All existing token/component imports load as `org.linura.UI 1.0`; S10/S16 behavior unchanged | Missing module, changed token semantic/status, raw per-panel independent styles |
| Preference schema | Strict typed known keys/mode/palette/revision under authenticated owner, canonical serialization | Unsupported/newer schema, injected QML/script, unsafe values or foreign owner |
| Local persistence | Atomic owner-only CAS, durable revision/readback, migration and restart | Concurrent editors, stale revision, torn disk/full store, corrupt state, replay |
| Preview/cancel | Window/session-scoped ephemeral preview with original committed state unchanged | Timeout, lock/logout, shell crash, second preview, stale Apply |
| Mode and palette | Same effective semantic token mapping in all supported presentation consumers | SystemPalette divergence, invisible warning/failure, low contrast or stale revision |
| Reduced motion/density | User accessible override propagated consistently to component transitions and focus geometry | Accessibility override ignored, shrunken controls, broken keyboard/pointer focus |
| Typography | Installed allowlisted family, bounded scaling, multilingual glyph/RTL fallback | Missing/unsafe font, excessive scale, clipping, fontconfig privilege mutation |
| Icons | Installed trusted icon set, safe fallback and limited resource formats | Malicious SVG/URI/external references, missing icons, alpha/scale errors |
| Wallpaper asset | Safe owner-scoped regular file/digest/MIME/size and actual decoded dimensions | Symlink/hardlink replacement, decompression bomb, remote URI, unsafe parser |
| Wallpaper per output | User-selected exact current compositor topology/transform/scale; genuine observed renderer state | S21 hotplug/rotation, stale output name, changed bytes, failed backend |
| Native scheme effect | Only separately registered user-session provider, exact source/state and independent applied result | QML shell command, failed provider, no postcondition, stale approval/restart |
| First Boot and installer | Same reviewed versioned token semantics where supported without extending UI policy | First Boot absent user/ownership, mismatched tokens, unqualified UX shortcut |
| S17 lock and prompts | Fixed protected focus/input, packaged secure fonts, visible warnings even with custom palette | User theme alters protected password screen or security severity states |
| Interface parity | Control Center, Quick Settings, manual CLI/SDK, no-model/accessible preview/Apply/Cancel | Optimistic "saved/applied", inaccessible focus, failed restart reconstruction |
| Recovery | Separate committed preference vs applied renderer, fallback, CAS restore and native no-replay | Lost reply, corrupt asset/store, compositor death, partial per-screen update |

A current stored preference is `LinuraOwnedState`; effectful wallpaper/desktop writes remain conservative disabled managed candidates. `ExperienceEphemeral` preview must not persist or dispatch an effect. Local CAS revision check and independently re-read commit are not the same as observing renderer output. For each eventually enabled managed effect exercise the complete trusted request/observe/plan/validate/authorize/prepare/execute/verify/commit/audit/reconcile lifecycle and failure/denial/restart/indeterminate paths.

## Evidence levels

**A — automated exact-source Arch/Hyprland VM:** Production compiled QML module and actual renderer using pinned Qt/Quickshell/Hyprland, real user-local preference storage where implemented, native wallpaper provider where claimed, adversarial parser/asset/revision tests and visual RGBA baseline/failed-diff evidence. Mock preference test without running QML is contract-level, not native visual proof.

**B — interactive exact-source VM:** Real preview/cancel/apply flows, changing mode/palette/scale/motion/icon/wallpaper on installed shell, keyboard/pointer/screen-reader/RTL/reduced motion, focus, multi-scale visual review, offline/no-AI and restart recovery. Do not confuse a recorded video with executed contrast/accessibility proof.

**C — maintained physical workstation/Q11:** Real GPU/display/input, representative physical monitors/HiDPI/hotplug and accessibility, S17 native protected lock and actual per-output wallpaper with independent source/boot/seat/environment-provenance and valid reviewed visual baselines. VM captures/fixtures cannot substitute.

Preserve S10/S16 SDK/launcher, S17 protected owner, S21 output/topology, v0.9 source and v0.10 Q9–Q14, exact-head canonical/security/CodeQL/qualification gates. No Q10 or Q11 promotion occurs by writing an ADR, contract, PNG or static test alone.
