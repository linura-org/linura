# v0.10 S23 security qualification — Arch package trust and MIME handler safety

**Status:** Proposed adversarial contract, no native security evidence yet.
**Sources:** [ADR 0052](../adr/0052-s23-application-package-and-default-handler-authority.md), [domain qualification](v0.10.0-s23.md), [system threat model](../threat-model.md).

## Threat objective

No catalog, mirror, signature, executable desktop file or untrusted agent can manufacture a privileged package approval, change the package universe after review, use an unsafe pacman option, redirect an XDG handler, or replay an ambiguous native transaction. Package signatures prove source origin under its trusted keyring—not benign scriptlets.

| Threat | Adversarial test | Required outcome |
| --- | --- | --- |
| Partial Arch upgrade | `pacman -Sy pkg`, database refresh without full upgrade, old package closure | Deny/defer to qualified S24; never unsafe partial install |
| Untrusted repository | AUR, PKGBUILD, arbitrary archive, mirror swap, unsigned source | Frozen repository/keyring attestation denies |
| Signature/keyring drift | Expired/revoked package key or changed SigLevel | No effect; replan with native proof |
| Dependency closure drift | Replaces/provides/conflicts/removals differ from reviewed plan | Invalidate permit and material risk |
| Package scriptlet | Hook invokes root service/changes protected files unexpectedly | Cannot classify as harmless; review and recover |
| ALPM lock and competing upgrade | Foreign pacman or S24 lock while prepared | No duplicate package transaction |
| Protected packages | Remove Linura, boot, PAM, Polkit, kernel/session or shared Setup deps | Protected owner/reverse-dependency denial |
| Root shell and force flags | `--nodeps`, `--overwrite`, `--dbonly`, arbitrary CLI/env injection | Only bounded native typed adapter accepted |
| Break-glass laundering | `LINURA_ALLOW_DIRECT_PACMAN`/`LINURA_UPDATE_CONTEXT` user-supplied | Environment not Linura approval/executor |
| Scriptlet/disk/boot interruption | Power loss, disk full, crash, native reply lost after execution | Durable indeterminate, reobserve; no blind replay/rollback claim |
| False package success | Correct exit but different installed version/file ownership | Independent postcondition rejects |
| Desktop entry substitution | ID overridden, altered Exec or changed NoDisplay/Terminal | Existing exact lookup/broker remains safe |
| MIME hijack | Hostile `x-scheme-handler/https` selected, missing association | Actual app provenance and explicit handler consent |
| XDG priority conflict | Higher-precedence default shadows new user choice | Independent effective lookup; not falsely verified |
| MIME edit race | Symlink, hardlink, UID mismatch, concurrent file overwrite | Safe descriptor, revision and atomic reject |
| Reset reveals unwanted fallback | User default removed but system default remains | Show actual fallback, never assert "none" |
| Classified operation substitution | GUI/provider tries transient install or weaker risk | Trusted registry denies |
| Cross-user subject | Foreign UID, administrative root laundering or stale session | Actual trusted principal and Polkit denies |
| Unknown restart | Previous prepared transaction repeats after daemon crash | Reconcile; never duplicate scriptlets |
| Offline/provenance confusion | Stale catalog displayed as current and installable | Stale/unknown, no effect |
| Model/log exposure | Arbitrary Exec, package args/credentials exposed in audit | Sanitized bounded state, no secrets |
| VM→Q11 confusion | Virtual package install claimed as physical/power cut | Physical and S24 evidence remain unqualified |

Exact-source native evidence binds all package hashes, repository and keyring, ALPM lock/DB epoch, scriptlets, target root/boot, subject and verified postcondition. No generic privileged shell, unreviewed AUR source, force flag, rollback promise or authority promotion is allowed by proposed docs or passing contract tests.
