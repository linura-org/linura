# Native output protocol source

`wlr-output-management-unstable-v1.xml` is vendored unchanged from Hyprland
v0.56.2, Git blob `411e2f0493f73779b9df59c342709708b4624363`:
https://github.com/hyprwm/Hyprland/blob/v0.56.2/protocols/wlr-output-management-unstable-v1.xml

Its permission and copyright notice are retained in the XML. CMake generates
private protocol bindings with the prepared Wayland scanner; generated files
are build outputs. A protocol definition or test acknowledgement is not proof
of backend atomicity, layout support, authority or independent verification.
